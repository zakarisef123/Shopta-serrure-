# Images du site

Déposez les images **originales** (jpg, png, webp ou svg) dans le bon dossier, avec **exactement** le nom indiqué
(en minuscules, sans accent ni espace ; seule l'extension est libre). À chaque déploiement, le site les recadre,
les optimise et les convertit en WebP. ✅ = déjà présent, ❌ = à fournir.
