# Images du site

Déposez ici les images **originales** (jpg, png ou webp). À chaque déploiement,
le site les recadre, les agrandit ou les réduit, renforce leur netteté et les
convertit en WebP dans `assets/img/`.

## Photos : `_src/images/photos/`

| Nom du fichier (extension libre) | Où elle apparaît |
|---|---|
| `serrurier-ouverture-porte` | Porte claquée (serrurier casquette rouge qui ouvre la porte) |
| `serrurier-crochetage` | Serrure bloquée (serrurier qui crochète une porte vitrée) |
| `cle-serrure-porte-blindee` | Clé cassée (main avec trousseau sur porte blindée) |
| `changement-cylindre` | Changement de serrure (mains qui posent un cylindre) |
| `serrurier-conseil-clients` | Serrure connectée + section « Notre façon de travailler » (serrurier avec un couple) |
| `porte-effraction` | Après effraction (porte fracturée) |
| `porte-rouge` | Article « sécuriser sa porte d'entrée » (porte rouge) |
